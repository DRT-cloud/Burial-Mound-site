ZOOM & BOOM YOUTH BIATHLON

A .22LR rifle-only biathlon through the fields and woods of Pawnee County. Your kid runs the same course and the same stage locations as the Twilight Biathlon that runs later that same evening — different targets sized for .22s, same terrain, same format, same clock.

Parents run with their kids. Parents do not shoot, do not carry the rifle, and do not help on stages or obstacles. The point is for the kids to do it themselves and walk away understanding how a Run N Gun actually works.

DIVISIONS

Three divisions. Pick the one that matches your kid's age and experience — not the one that sounds better.

8–13 Years Old

  • Runs with a parent or adult run buddy
  • Adult is present for safety and moral support only
  • No prior competition experience required

14–17 With Run Buddy

  • Runs with a parent or adult run buddy
  • For shooters brand new to shooting sports
  • Adult is present for safety and moral support only

14–17 Solo

  • Runs the course alone — no run buddy
  • Must have Run N Gun or other shooting sport experience
  • Do not enter this division to skip the buddy requirement

RIFLE & GEAR

.22LR rifle only. Any action type, any barrel length. What matters is that the rifle fits your kid and that your kid can run it without help.

Required

  • .22LR rifle — any action, any barrel length
  • A stock or a brace
  • A sling
  • Pouches to carry spare magazines

Non-Negotiable

  • Your kid must already know how to operate the rifle
  • No loaded firearms while running the course — ever
  • Adults running with kids are held to the same rules
  • Read every Burial Mound rule before you arrive

Plan For

  • No food or beverages provided at this event

HOW THE FORMAT WORKS

This runs exactly like the Twilight Biathlon. If you have never shot that format, read this twice.

01

You Get a Run Number

Assigned at check-in. Whether that number is odd or even determines which stages your kid shoots on which lap.

02

First Lap

Even run number: shoot the even-numbered stages. Odd run number: shoot the odd-numbered stages. Run past the others.

03

Second and Final Lap

Flip it. Even run numbers now shoot the odd stages; odd run numbers shoot the even stages. Every competitor shoots all 4 stages across the two laps.

04

Obstacles Along the Way

Slack lines, walls, and low crawls, plus whatever the terrain throws at you. Run buddies do not assist unless there is a genuine safety issue.
